# Multiplayer Snake

Лаунчер мультиплеера для **Minecraft PE 1.1.5**.

## Интерфейс (APK) — 0.8.0

Тёмно-зелёная pixel-тема:
- Вход / регистрация
- Список активных миров
- Кнопка **+** снизу по центру → открывает Minecraft + оверлей
- В Minecraft: тап по плавающей кнопке → «Начать хост?» → название / описание / игроки → хост
- Выход из Minecraft / возврат в лаунчер → хост сразу закрывается
- Профиль (имя, возраст, семья, специализация) сохраняется в БД
- Друзья, ЧС, кланы

## Как хостить

1. В лаунчере на экране «Миры» нажми **+**
2. Откроется Minecraft PE
3. Зайди в любой свой мир
4. Нажми плавающую кнопку-змею
5. «Начать хост?» → **Да**
6. Укажи название, описание, макс. игроков → **Начать**
7. Мир появится в общем списке, игроки смогут присоединиться
8. Выйди из мира / вернись в лаунчер — хост остановится автоматически  
   (или нажми «Остановить хост» в панели оверлея)

## Сборка APK

1. GitHub → репозиторий `multiplayer-snake`
2. **Actions** → **Build APK** → **Run workflow**
3. Дождись окончания (15–40 мин)
4. Скачай artifact `multiplayer-snake-apk`
5. Установи APK на телефон

## Бэкенд

Папка `backend/` — Flask API (`main.py`).  
Хостинг: Render + `DATABASE_URL` (Neon).

API по умолчанию: `https://snake-master-3pzr.onrender.com`

## Важно про Google Play

Google Play часто отклоняет неофициальные лаунчеры Minecraft.  
Публикация вне Play (сайт / Telegram) или сильная переработка под правила Google.
